# Pytorch

### Chapter 1: 

To begin we will create an virtual environment using conda. Let the name of the environment be `pytorch`.

Please install the Anaconda. 
<!-- Add the link -->

Now open the terminal in the VS Code (or your IDE).
And Run the following in Powershell.

```Powershell
conda create -p venv python==3.10 -y
# this will create your environment, named `venv` in 
# the current directory, with saying yes to all the confirmations.
conda activate venv/
# activates the environment
```

Now install the Pytorch.
```Powershell
pip3 install torch torchvision torchaudio
```
wait for a minute or two.
